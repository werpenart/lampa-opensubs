# Lampa OpenSubs

Плагин для [Lampa](https://github.com/yumata/lampa): субтитры [OpenSubtitles](https://www.opensubtitles.com) во встроенном плеере.
Работает целиком в Lampa и не требует своего сервера.

## Установка

Lampa → Настройки → Расширения → Добавить плагин:

```
https://cdn.jsdelivr.net/gh/werpenart/lampa-opensubs@main/opensubs.js
```

Затем Настройки → **OpenSubtitles** → **API-ключ**: свой ключ с opensubtitles.com (Профиль → API consumers).

## Что умеет

- При запуске видео ищет субтитры к фильму или конкретной серии (по TMDB/IMDb) и добавляет их
  к субтитрам источника; машинные и AI-переводы отсеиваются.
- Подбирает субтитры к финальным релизам (BluRay, WEB-DL и т. п.), экранки (CAM, TS) пропускает.
- Кнопка субтитров в плеере рядом с выбором качества: язык субтитров, размер шрифта, тень, синхронизация.
- Синхронизация «по фразе»: выберите реплику, которая звучит сейчас; повторите через 10+ минут —
  подберётся и скорость (разная частота кадров). Плюс ручной сдвиг и выбор частоты кадров. Запоминается.
- Скачанные файлы хранятся на устройстве (до 300): повторный просмотр не тратит дневной лимит OpenSubtitles.
- Настройки: языки (рус/укр/англ), вариантов на язык, уведомления, очистка сохранённых субтитров.

Ограничения: только встроенный плеер Lampa (во внешние плееры субтитры не передаются);
лимит OpenSubtitles без аккаунта — около 100 скачиваний в сутки.

Иконка — [Lucide](https://lucide.dev) «captions» (ISC).
